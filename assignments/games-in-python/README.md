# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construa o clássico jogo de adivinhar palavras em Python, praticando manipulação de strings, loops, condicionais e entrada de dados do usuário.

## 📝 Tarefas

### 🛠️ Desenvolver o Jogo da Forca

#### Descrição
Crie um jogo da Forca em que o jogador tente descobrir uma palavra secreta informando uma letra por vez antes que suas tentativas se esgotem.

#### Requisitos
O programa concluído deve:

- Selecionar palavras aleatoriamente de uma lista predefinida.
- Solicitar ao jogador que informe uma letra por vez.
- Mostrar o progresso da palavra no formato `_ _ _`.
- Rastrear e informar as tentativas incorretas restantes.
- Encerrar o jogo quando a palavra for descoberta ou as tentativas se esgotarem.
- Exibir uma mensagem de vitória ou derrota ao final da partida.
